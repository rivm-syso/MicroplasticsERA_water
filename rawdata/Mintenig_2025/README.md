# ReadMe Mintenig et al. (2025)

# Owner

The data in this folder was created as part of the study by Mintenig et al. (2025). The individual particle measurement data is not published elsewhere and is made available as part of this repository under [European Union Public Licence, Version 1.2 (EUPL)](https://spdx.org/licenses/EUPL-1.2).

# Citation

When using this data cite the original study.

Mintenig, S.M., Hunnestad, A., Koelmans, A.A., 2025. Microplastics in het oppervlaktewater van de Dommel. Wageningen University & Research.

# About the files in this folder

**readme.xlsx** contains metadata on each of the measured concentrations. This information was obtained from Mintenig et al. (2025).  

**Concentrations.xlsx** contains the concentrations reported in Mintenig et al. (2025).  

**MP_Dommel_WUR_2025.xlsx** contains the individual particle measurements, and was provided by Svenja Mintenig.
