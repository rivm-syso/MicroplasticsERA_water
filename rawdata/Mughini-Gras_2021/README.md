# ReadMe Mughini-Gras et al. (2021)

# Owner

The data in this folder was created as part of the study by Mughini-Gras et al. (2021) published under a [Creative Commons license.](http://creativecommons.org/licenses/by-nc-nd/4.0/) The individual particle measurement data is not published elsewhere and is made available as part of this repository under [European Union Public Licence, Version 1.2 (EUPL)](http://spdx.org/licenses/EUPL-1.2).

# Citation

When using this data cite the original study.

Mughini-Gras, L., van der Plaats, R.Q.J., van der Wielen, P.W.J.J., Bauerlein, P.S., de Roda Husman, A.M., 2021. Riverine microplastic and microbial community compositions: A field study in the Netherlands. Water Research, 192, 116852. <https://doi.org/10.1016/j.watres.2021.116852>

# About the files in this folder

**readme.xlsx** contains metadata on each of the measured concentrations. This information was obtained from the publication.

The other Excel files in the folder each contain the individual particle measurements of one sample. These files were provided by Patrick Bäuerlein.
