rawdata
================

Here the data, mostly from others is (partly) made available to run the
analysis part of RIVM letter report 2026-0069. Other data can be made
available upon request.

# Folders

Each of the subfolders contain microplastics data as created in the
respective original studies. A brief description is provided seperately
in their respective readme files.

# Overview files

## Coffin_PSSDs.xslx

**Coffin_PSSDs.xslx** contains the PSSD values from Table 2 in the
publication by Coffin et al. (2026).

### Citation

When using this data cite the original study.

Coffin, S., Bertrand, L., Ahmed, K.T., de Souza Leite, L., Cowger, W.,
Siña, M., Barrick, A., Kukkola, A., Carney Almroth, B., Miller, E., Yeh,
A., Kennedy, S., Mair, M.M., 2026. A probabilistic risk framework for
microplastics integrating uncertainty across toxicological and
environmental variability: Development and application to marine and
freshwater ecosystems. Journal of Hazardous Materials 503, 141021.
<https://doi.org/10.1016/j.jhazmat.2025.141021>

## QAQC Scores_IR_Studies.xlsx

**QAQC Scores_IR_Studies.xlsx** contains the QA/QC scores of the
studies.

### Citation

When using this data cite RIVM report 2026-0069.

Quik, J.T.K., van Breemen, P., Hids, A.R., van Loon, S., Mintenig, S.M.,
Koelmans, A.A., 2026. Screening level ecological risk assessment of
Microplastics in Dutch surface waters. (No. 2026–0069). RIVM, Bilthoven.
