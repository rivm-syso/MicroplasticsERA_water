# ReadMe Leslie et al. (2017)

# Owner

The xlsx file in this folder contains the concentrations of microplastics in water as reported in Table 1 of Leslie et al. (2017) \# Citation

When using this data cite the original study.

Leslie, H.A., Brandsma, S., Velzen, M.J.M., Vethaak, A., 2017. Microplastics en route: Field measurements in the Dutch river delta and Amsterdam canals, wastewater treatment plants, North Sea sediments and biota. Environment International 101. <https://doi.org/10.1016/j.envint.2017.01.018>
