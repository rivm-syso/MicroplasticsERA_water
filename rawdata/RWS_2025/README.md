# ReadMe Rijkswaterstaat 2025

# Owner

The data in this folder was created by Rijkswaterstaat, and partly published in Freriks et al. (2023). 

The raw data was not published elsewhere and is made available as part of this repository under [European Union Public Licence, Version 1.2 (EUPL)](https://spdx.org/licenses/EUPL-1.2).

# Citation

Freriks, I., Oversteeg van, C., Zemmelink, H., 2023a. Op weg naar microplastics monitoring in rivieren - Deel 1: Bemonstering. Rijkswaterstaat, Centrale Informatievoorziening.
Freriks, I., Oversteeg van, C., Zemmelink, H., 2023b. Op weg naar microplastics monitoring in rivieren - Deel 2: Analyse van microplastics. Rijkswaterstaat, Centrale Informatievoorziening.

# About the files in this folder

**readme.xlsx** contains metadata on each of the measured concentrations. This information was obtained from Freriks et al. (2023a, 2023b, 2023c).

**20250502 TED GC-MS data voor RIVM.xlsx** contains the mass concentrations per polymer. This data was provided by Christa van Oversteeg.

**zwevend stof gehalte Eijsden 2020-2024.csv** contains the suspended particulate matter concentrations in Eijsden. This data was provided by Christa van Oversteeg.

**zwevend stof gehalte Lobith 2020-2024.csv** contains the suspended particulate matter concentrations in Lobith. This data was provided by Christa van Oversteeg.
