# ReadMe Mintenig et al. (2020)

# Owner

The data in this folder was created as part of the study by Mintenig et al. (2020) published under a [Creative Commons license](https://creativecommons.org/licenses/by/4.0/). The individual particle measurement data is not published elsewhere and is made available as part of this repository under [European Union Public Licence, Version 1.2 (EUPL)](https://spdx.org/licenses/EUPL-1.2).

# Citation

When using this data cite the original study.

Mintenig, S.M., Kooi, M., Erich, M.W., Primpke, S., Redondo- Hasselerharm, P.E., Dekker, S.C., Koelmans, A.A., van Wezel, A.P., 2020. A systems approach to understand microplastic occurrence and variability in Dutch riverine surface waters. Water Research 176, 115723. <https://doi.org/10.1016/j.watres.2020.115723>

# About the files in this folder

**readme.xlsx** contains metadata on each of the measured concentrations. This information was obtained from Mintenig et al. (2020).

**Mintenig_2020_reported_concentrations_from_paper_SI.xlsx** contains the reported concentrations from Table S3 in the supplementary information of Mintenig et al. (2020).

**Mintenig_2020_SurfaceWater.xlsx** contains the individual particle measurements, and was provided by Svenja Mintenig.
