ReadMe Output folder
================

# Data.zip

The folder Data.zip contains the datasets created with the code in this
repository that was used to generate the tables and figures featured in
RIVM report 2026-0069. If you unzip the Data.zip folder you can use
these datasets to generate your own tables and figures.
